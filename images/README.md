# Photos go here

Drop your real press-on nail photos into this folder using these exact
filenames, and they'll automatically appear on the site — no code changes
needed.

| Filename           | Used for                          | Suggested shape |
|---------------------|------------------------------------|------------------|
| `hero.jpg`          | Big photo at the top of the page   | 4:3 landscape    |
| `gallery-1.jpg`     | Gallery grid, top-left             | Square (1:1)     |
| `gallery-2.jpg`     | Gallery grid, top-right            | Square (1:1)     |
| `gallery-3.jpg`     | Gallery grid, bottom-left          | Square (1:1)     |
| `gallery-4.jpg`     | Gallery grid, bottom-right         | Square (1:1)     |

Until a file is added, that spot shows a striped placeholder with the
expected filename printed on it, so it's obvious what's missing.

Tips:
- `.jpg`, `.jpeg`, `.png`, and `.webp` all work — just make sure the
  filename (before the extension) matches exactly, and update the `src`
  in `index.html` if you use a different extension.
- Keep files under ~500KB each for fast loading on mobile data.
